# Astri Wide Record

An extra canvas for OBS Studio with its own resolution (default 3840x1080), scenes, sources and recording output,
so a wide side-by-side recording (gameplay + camera) can be made while streaming.

Based on [Aitum Vertical](https://github.com/Aitum/obs-vertical-canvas) by Aitum and Exeldro, licensed under GPL-2.0.
This fork renames all identifiers so it runs side by side with Aitum Vertical, defaults to 3840x1080,
and removes the update/partner check against Aitum servers.
